\# RailKavach AI (v2)



Crowd early-warning for railway stations. Team Code Red.



\## Run



Backend:

&#x20;   cd backend

&#x20;   python -m venv .venv

&#x20;   .venv\\Scripts\\Activate.ps1

&#x20;   pip install -r requirements.txt

&#x20;   uvicorn main:app --reload --port 8000



Frontend:

&#x20;   cd frontend

&#x20;   npm install

&#x20;   npm run dev
